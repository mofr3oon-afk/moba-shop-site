# مراجعة المشروع الحالي

المستودع المؤكد: `mofr3oon-afk/moba-shop-site`، وليس نسخة Python القديمة في `moba-shop-bot`.
نقطة البداية لهذا الفرع: main عند `765f1d1ab8aa0d687bb9d96277c438f8a88f1c92`، وهو الإصدار الذي أكد المستخدم تشغيل فحص الاسم فيه بصورة من Telegram.

## البنية الحالية

| المجموعة | الوظيفة |
|---|---|
| `api/telegram.js` | Telegram webhook، سر webhook، صلاحيات الأدمن، تحديث طلبات الموقع، التقارير والكوبونات |
| `lib/pubg-lookup.js` | فحص ID واسم اللاعب من GoPay، وتوحيد الأرقام ومهلة المزود |
| `lib/telegram-pubg.js` | البحث في الخاص وتنسيق الاسم وزر Telegram الأصلي لنسخه |
| `lib/telegram-menu.js` | قائمة زر الفحص الواحد والتوافق مع الأزرار القديمة |
| `api/order.js` | إنشاء طلبات الموقع وإرسالها إلى Supabase وTelegram |
| `api/admin-orders.js`, `api/settings.js` | إدارة الطلبات والإعدادات |
| `api/admin-login.js`, `lib/admin-auth.js`, `lib/_security.js` | دخول الإدارة والتحقق والصلاحيات وتحديد المعدل |
| `api/public.js`, `api/report.js`, `api/health.js`, `lib/handlers/*` | البيانات العامة والصحة والتقارير والكوبونات والتقييمات وتصحيح الطلب |
| `lib/_utils.js` | أدوات Supabase/Telegram وعرض حالات الطلبات |
| `index.html`, `admin.html`, `js/*`, `styles/*` | صفحات المتجر والإدارة وسلة الشراء والتتبع |
| `public/*` | نسخ الأصول والواجهة الحالية؛ لم نغيرها في هذه الإضافة |
| `*.sql` | إعداد وتحديث جداول Supabase القديمة؛ لم نطبق SQL أو نعدل قاعدة منشورة |
| `vercel.json` | وظائف Node وRoutes الحالية، بحد 30 ثانية للوظيفة |
| `assets/*` | صور الألعاب والمتجر والتقييمات؛ ليست كود البوت |

لغة المشروع JavaScript بنظام ES Modules، دون dependencies في package.json الأصلي. البوت يعمل باستقبال Webhook على Vercel، لا يحتاج كمبيوتر المستخدم. مخزون الشحن الجديد لا يحاول الكتابة إلى قرص Vercel المؤقت.

تم جرد 151 ملفًا من النسخة الأصلية، منها 53 ملف مصدر/إعداد/توثيق، وفحص syntax لـ36 ملف JavaScript بنجاح دون تنفيذ ملفات الواجهة أو استيراد الأسرار. ملف الجرد المرفق في التسليم يحتوي المسارات والأحجام والبصمات وتصنيف الأصول. المراجعة لا تدعي اختبار جميع صفحات الموقع بصريًا أو جميع خدمات Supabase الحية.

## حدود التعديل للحفاظ على الموجود

التعديل الوحيد داخل handler الحالي هو بوابة اختيارية قبل التوجيه القديم. `TOPUP_ENABLED` غير مضبوط افتراضيًا، فيعود السلوك السابق بالكامل. أضيف زر شراء فقط عند تفعيل البوابة لاحقًا؛ زر فحص الاسم ونسخه وأوامر الإدارة الأصلية محفوظة. لا تغيير في أسعار الموقع أو بيانات الدفع أو جداول Supabase أو Website assets أو webhook/token في الاستضافة.

كل كود مالي جديد في `topup/`، مع tests مستقلة واختبارات الرجوع القديمة. الأسماء والأكواد التجريبية والمحافظ في الاختبارات وهمية. لا توجد جلسة Midasbuy أو كلمة سر أو Cookie في الكود.
